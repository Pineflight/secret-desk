# Support

- **Getting started and how-tos:** [docs/GETTING-STARTED.md](docs/GETTING-STARTED.md), [docs/FAQ.md](docs/FAQ.md) and [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md). The documentation index is [docs/README.md](docs/README.md).
- **Bugs and feature requests:** open an issue at [Pineflight/secret-desk](https://github.com/Pineflight/secret-desk/issues) using the templates. Include the output of `secret-desk doctor` and the portal's message, **never a secret value or token**.
- **Security vulnerabilities:** do **not** open a public issue. Use GitHub's private vulnerability reporting, see [SECURITY.md](SECURITY.md).
- **Contributing:** [CONTRIBUTING.md](CONTRIBUTING.md).

secret-desk is an early, open-source project maintained on a best-effort basis; there is no service-level agreement.
